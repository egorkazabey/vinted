# Vinted Bot

Телеграм-бот, который следит за новыми объявлениями на Vinted (по умолчанию vinted.cz)
по списку брендов и ценовому лимиту, и присылает их в чат.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Впишите в `.env` токен бота (получить у [@BotFather](https://t.me/BotFather)).
При необходимости поменяйте `VINTED_DOMAIN` (vinted.cz, vinted.pl, vinted.de, ...).

## Запуск

```bash
python main.py
```

## Команды бота

- `/addbrand <название>` — добавить бренд для отслеживания (если находится несколько
  похожих брендов, бот предложит выбрать нужный кнопками)
- `/removebrand <название>` — убрать бренд
- `/brands` — список отслеживаемых брендов
- `/setprice <сумма>` — максимальная цена объявления
- `/noprice` — снять ограничение по цене
- `/status` — текущие настройки чата
- `/pause` / `/resume` — приостановить/возобновить уведомления

Бот начинает присылать объявления только после того, как в чате добавлен хотя бы
один бренд. При первом добавлении бренда бот не присылает всю историю объявлений —
только те, что появятся после этого момента.

## Как это работает

Бот использует внутренний REST API веб-версии Vinted (`/api/v2/catalog/items`),
опрашивая его каждые `POLL_INTERVAL_SECONDS` (по умолчанию 90) для каждого чата
с активными брендами. Это неофициальный API — сайт может менять его формат без
предупреждения, будьте готовы, что что-то может со временем сломаться.

Публичного эндпоинта для поиска бренда по названию у Vinted нет, поэтому бот находит
бренд через полнотекстовый поиск объявлений и извлекает числовой id бренда со страницы
конкретного товара — это происходит один раз при добавлении бренда, не при каждом опросе.
